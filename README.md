## 🚀 How to Run / Preview

### Option 1: Direct Browser Opening
Simply double-click or open [index.html](file:///c:/Users/techn/OneDrive/Desktop/vivek%20projects%20(1)/vivek%20projects/converted/index.html) in any modern browser (Chrome, Edge, Firefox, Safari).

### Option 2: Using VS Code Live Server
Right-click on `index.html` in VS Code and select **"Open with Live Server"**.

### Option 3: Using Python HTTP Server (if Python is installed)
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.

## ✨ Features & Optimizations
- **100% Standalone & Local**: All external WordPress dependencies, plugins, and remote assets are replaced with local, high-speed static assets.
- **Pixel-to-Pixel Replication**: Typography (Montserrat, Roboto Slab, Roboto), layout grids, banners, counters, partner logos, header navigation, dropdowns, and footer match the original site.
- **Responsive & Mobile Ready**: Full support for desktop, tablet, and mobile portrait/landscape views including interactive hamburger menu and sub-menu dropdowns.
- **Interactive Handlers**: Custom script (`assets/js/custom-interactions.js`) powers mobile menus, animated counters, smooth scroll, and interactive sliders.
